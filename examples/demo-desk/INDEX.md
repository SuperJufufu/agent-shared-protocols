# 演示桌面索引

这是一个**虚构**的小工作台：一台叫 `demo-host` 的机器，服务跑在 `/home/user/desk`。它同时演示两件事 —— 用 `read_when` 只读需要的那一份，以及共享数据怎么认领和回读。

## 怎么读

1. 在下表里找 `read_when` 命中你这次任务的那一行。
2. 只读那一份；要读第二份时先说明理由。
3. 引用端口、路径时带上子文档名，方便回查。

## 文档

| 文档 | read_when | 权威 |
|---|---|---|
| [01-服务与端口.md](01-服务与端口.md) | 改端口、加服务、动启动器或自启动项、排查服务没起来时 | shared/state.md |
| [02-备份与恢复.md](02-备份与恢复.md) | 改前要备份、要恢复某次改动、外置盘没挂载时 | 是 |
| [03-变更记录.md](03-变更记录.md) | 想知道某次改动是谁做的、要追加一条变更时 | 是 |

## 总则

- 改前先备份，改完回读，再追加一条变更。
- 服务与端口的事实只以 `shared/state.md` 为准，别处出现的一律当缓存。
- 两份说法冲突时，以 `last_updated` 较新者为准。
