# 变更记录

**只追加**：新条目加在最上面，旧条目一个字都不改。要纠正旧条目，就再加一条说明，而不是回去编辑它。

格式：`时间 · agent · 位置 · 做了什么`。

- 2026-11-23 23:10 · dsh · 全仓 · 拆成 3 份子文档 + 索引，建立共享数据契约
- 2026-11-23 22:40 · codex · shared/state.md#端口 · 新增 8090（演示服务）
- 2026-11-23 21:15 · claude-code · 02-备份与恢复.md · 补上「外置盘没挂载就别备份」

## 为什么只追加

历史是证据。允许改旧行之后，「谁在什么时候改了什么」就不再可信 —— 而这正是并发写入时唯一能事后裁决的东西。
